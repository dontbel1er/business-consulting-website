## Что сделано

Редизайн по скиллу `apple-design` (Apple: материалы, пружины, типографика).

- **Дизайн-система** — `src/index.css` переписан: токены (цвет/радиус/отступы/тени),
  размерно-зависимый трекинг и интерлиньяж, `font-optical-sizing`, зеркальные easing-пары.
- **Акцент** приведён к единому Action Blue `#0066cc` (было `#1d1d1f` в кнопках) —
  теперь соответствует собственному `DESIGN.md`.
- **Навигация** — плавающая: `position: fixed`, `backdrop-filter`, сжатие 52→48px при
  скролле, скролл-эффект вместо хард-разделителя, сегментированный переключатель языка,
  пружинный индикатор активной ссылки, пружинное мобильное меню-шит.
- **Тёмная плитка** (`Roadmap`) вместо белой карточки с рамкой — ритм плиток
  белый → тёмный → белый → белый → футер-стекло.
  (Секция «Почему выбирают меня» переведена с пергамента на белый — как hero.)
- **Пружины вместо CSS-переходов** там, где элемент можно тронуть: аккордеон FAQ,
  модалка заявки, мобильное меню, активная ссылка, счётчики.
- **Модалка заявки** — spring in/out через портал в `document.body`, фокус-ловушка,
  Escape, блокировка скролла, инлайн-валидация по blur, состояние успеха.
- **Reveal-on-scroll** — `src/lib/motion.jsx`, `useRevealed()`: IntersectionObserver
  **плюс** проверка rect на скролле (быстрый флик/End/переход по якорю не оставляют
  контент скрытым), плюс `visibilitychange` для фоновой вкладки.
- **Типографика** — свой трекинг на каждый размер (крупный −0.022em, мелкий +0.01em),
  лестница весов 300/400/600 без 500.
- **Доступность** — `prefers-reduced-motion` (кросс-фейд вместо слайдов),
  `prefers-reduced-transparency`, `prefers-contrast`, focus-visible кольца,
  `aria-expanded`/`aria-controls` в аккордеоне, `role=dialog` + `aria-modal`.
- **Контент** — у каждой страницы свой заголовок в hero (был общий на все 4),
  ссылка в Telegram-карточке (была пустая), 3 пункта в мете-данных roadmap.
  Позже: логотип BConsult, описание и CTA-карточка убраны из футера; контакты
  заменены на заглушки; Telegram / YouTube / VK удалены полностью.
- **Фото-подложки по страницам** (везде один приём — фото + чёрный скрим + стекло):
  - `/` — тёмная плитка Roadmap (`hall.jpg`): `::before` — фото с
    `grayscale(100%) blur(8px)`, `opacity: 0.2`, маска растворяет его на верхней и
    нижней границах плитки; `::after` — градиент-скрим
    `linear-gradient(to right, rgba(30,30,30,0.95), rgba(30,30,30,0.8))`.
  - `/` — FAQ (`hall4.webp`): фото справа, `opacity: 0.3`, `blur(14px)`, маска по
    горизонтали **и** вертикали (`mask-composite: intersect`). Псевдоэлемент
    позиционирован → рисуется поверх текста, поэтому `.faq-question`,
    `.faq-answer` и заголовок секции подняты через `position: relative; z-index: 1`.
  - `/services` — секция услуг (`hall2.jpg`) под стеклянными карточками.
  - `/contacts` — секция контактов (`hall3.jpg`, единственный неиспользованный ассет)
    под стеклянными карточками; карта Яндекса в рамке `rgba(255,255,255,0.14)`.
  - `/about` — **чисто белый** фон (секция переведена с пергамента на `tile-light`).
  ⚠️ При `opacity: 0.1` эффект был невидим: пиксельный дифф давал максимум 24/255
  (≈9%). Поднято до 0.3–0.75 в зависимости от фона.
- **Стеклянные карточки (glassmorphism)** — каталог услуг и раздел «Контакты»:
  `rgba(255,255,255,0.10)` + `backdrop-filter: blur(24px) saturate(180%)`,
  рамка `rgba(255,255,255,0.16)`, текст переведён на светлый.
  Подложка — тёмный фотоблок в три слоя: фото (`::before`, z-index -2) → чёрный
  градиент-скрим (`::after`, z-index -1) → карточки. Маска по верхнему краю
  растворяется ровно на `var(--sp-section)` — к началу карточек фон уже тёмный
  (на мобильном процентная маска оставляла первую карточку на белом фоне).
  Контраст замерён по реальным пикселям: заголовок 7.23:1 (десктоп) / 6.10:1 (мобайл),
  мелкий текст 5.51:1 / 4.74:1 — AA везде.
- **Футер в material-стиле хедера** — материал вынесен на `::after`
  (`rgba(12,12,14,0.80)` + `backdrop-filter: saturate(180%) blur(20px)`),
  верхняя кромка размывается: `::before` — полоса 44px над футером с
  `backdrop-filter: blur(14px)` и маской, плюс `mask-image` на `::after`
  (проявление материала за 36px). Тон футера над белым полотном — `rgb(61,61,62)`.
  ⚠️ У `.footer` не может быть собственного `backdrop-filter`: он создаёт backdrop root,
  и вложенный блюр (`.footer::before`) перестаёт видеть страницу — та же ловушка,
  что была с мобильным меню. Поэтому материал живёт на `::after`, размытие кромки
  — на `::before`, а у самого `.footer` фона и блюра нет.
  Контраст текста на полупрозрачной поверхности — AA: ссылки 8.75:1, описание 5.89:1,
  копирайт 5.42:1, заголовки колонок 4.79:1.
  Токен `--void` (#1d1d1f) больше не используется — материал задаётся напрямую.
- **Структура футера упрощена** — верх: только две колонки (Навигация, Контакты),
  обе по центру футера (`justify-content: center`, пара симметрична относительно
