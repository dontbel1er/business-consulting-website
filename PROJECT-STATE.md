## Что сделано

Редизайн по скиллу `apple-design` (Apple: материалы, пружины, типографика).

- **Дизайн-система** — `src/index.css` переписан: токены (цвет/радиус/отступы/тени),
  размерно-зависимый трекинг и интерлиньяж, `font-optical-sizing`, зеркальные easing-пары.
- **Акцент** приведён к единому Action Blue `#0066cc` (было `#1d1d1f` в кнопках) —
  теперь соответствует собственному `DESIGN.md`.
- **Навигация** — плавающая: `position: fixed`, `backdrop-filter`, сжатие 52→48px при
  скролле, скролл-эффект вместо хард-разделителя, сегментированный переключатель языка,
  пружинный индикатор активной ссылки, пружинное мобильное меню-шит.
- **Тёмная плитка** (`Roadmap`) вместо белой карточки с рамкой — ритм плиток
  белый → тёмный → пергамент → белый → футер.
- **Пружины вместо CSS-переходов** там, где элемент можно тронуть: аккордеон FAQ,
  модалка заявки, мобильное меню, активная ссылка, счётчики.
- **Модалка заявки** — spring in/out через портал в `document.body`, фокус-ловушка,
  Escape, блокировка скролла, инлайн-валидация по blur, состояние успеха.
- **Reveal-on-scroll** — `src/lib/motion.jsx`, `useRevealed()`: IntersectionObserver
  **плюс** проверка rect на скролле (быстрый флик/End/переход по якорю не оставляют
  контент скрытым), плюс `visibilitychange` для фоновой вкладки.
- **Типографика** — свой трекинг на каждый размер (крупный −0.022em, мелкий +0.01em),
  лестница весов 300/400/600 без 500.
- **Доступность** — `prefers-reduced-motion` (кросс-фейд вместо слайдов),
  `prefers-reduced-transparency`, `prefers-contrast`, focus-visible кольца,
  `aria-expanded`/`aria-controls` в аккордеоне, `role=dialog` + `aria-modal`.
- **Контент** — у каждой страницы свой заголовок в hero (был общий на все 4),
  иконки в карточках контактов, ссылка в Telegram-карточке (была пустая),
  CTA-блок в футере, 3 пункта в мете-данных roadmap.
- **Мелочи** — SVG-фавикон, `description`/`theme-color`, ссылка на Яндекс.Карту.
